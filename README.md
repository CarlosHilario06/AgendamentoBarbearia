# Sistema de Agendamento para Barbearia

Um sistema moderno de agendamento para barbearias, inspirado no InBarber. Permite que barbeiros gerenciem seus horários e clientes façam agendamentos online.

## 🚀 Stack

- **Frontend:** Next.js 14+ (React)
- **Backend:** Node.js + Express
- **Banco de Dados:** PostgreSQL
- **Autenticação:** JWT
- **Deploy:** Vercel (Frontend) + Railway/Render (Backend)

## 📁 Estrutura

```
barber-schedule-system/
├── frontend/          # Next.js app
├── backend/           # Express API
├── docs/             # Documentação
└── README.md
```

## 🔧 Setup Inicial

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
